## Java TPC Chat
Chat cliente-servidor simple usando Socket y Threads

## Como ejecutar en Netbeans
1: Ejecutar el archivo ServerMain.java para ejecutar el servidor
2: Para ejecutar un cliente, ejecute Init.java, cada ejecucion de este iniciara un nuevo cliente.

## Advertencias
Tome esta version como 0.1.0

[] Este chat fue creado para aprender, en versiones futuras comentare el codigo para que lectores logren aprender conexiones en Java.

[] El Socket esta conectado al localhost, por lo que solo funcionara en la misma maquina, si se desea ejecutar en otras maquinas habria que modificar la ip en Socket.
